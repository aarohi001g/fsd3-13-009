BRIGHT FUTURE TUITION CLASSES - 5 PAGE HTML WEBSITE

Files:
1. registration.html
2. login.html
3. process.html
4. feedback.html
5. price-details.html
6. style.css

How to run:
- Extract the ZIP file.
- Open registration.html in a browser.
- Use the navigation bar to move between all pages.

Note:
- Forms are front-end only and do not save data to a database.
- Social media links use # placeholders. Replace them with your actual profile links.
- Font Awesome is loaded through CDN for the social media and other icons.
